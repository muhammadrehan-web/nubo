# Nubo (Next.js)

Framer site clone converted to Next.js App Router.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Legacy static HTML/CSS/JS (if needed for reference) lives in `_static-legacy/`. The live app is Next.js only: `app/`, `components/`, `styles/`, `public/assets/`.
